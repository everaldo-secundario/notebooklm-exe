# 📚 Segundo Cérebro — Direito Constitucional

## 🎯 Objetivo

Criar um ambiente de estudos utilizando o **Google NotebookLM** para organizar conteúdos de Direito Constitucional, facilitar a aprendizagem e obter respostas fundamentadas nas fontes disponibilizadas.

## 📖 Fontes utilizadas

O notebook reúne materiais de estudo sobre Direito Constitucional Brasileiro, priorizando fontes oficiais, legislação e conteúdos educacionais confiáveis.

## ⚙️ Diretriz do notebook

Responder de forma clara, objetiva e didática, utilizando as fontes fornecidas, apresentando citações e evitando informações sem fundamentação.

*Diretriz esperada — substituir pela instrução real, caso tenha sido configurada outra.*

Foram realizados testes para verificar a capacidade do NotebookLM de responder com base nos documentos.
